# セリフ一覧作成ツール

漫画の台本（Markdown 形式の `.md` ファイル）を読み取って、**写植用のセリフ一覧**を作るツールです。
Windows 11 で動きます。

できあがるもの：

| ファイル | 中身 |
|---|---|
| `○○_セリフ一覧.xlsx` | Excel の一覧表。1行＝1つの台詞。効果音の行はオレンジ色 |
| `○○_セリフ一覧.txt` | 本ごと・コマごとに台詞だけを並べたテキスト。写植ソフトへのコピペ用 |
| `○○_警告.txt` | チェックで見つかった問題のまとめ（問題がなければ「警告はありません」） |

完成見本は「**出力サンプル**」フォルダに入っています。まずはそれを開いてみてください。

## 1. Python を入れる（最初の1回だけ）

このツールは「Python（パイソン）」というソフトの上で動きます。

1. <https://www.python.org/downloads/> を開き、黄色い「**Download Python 3.x.x**」ボタンを押してダウンロードします。
2. ダウンロードしたファイルをダブルクリックしてインストールを始めます。
3. 最初の画面の下にある **「Add python.exe to PATH」に必ずチェック** を入れてから、「Install Now」を押します。
   （ここを忘れると、ツールが Python を見つけられません）
4. 「Setup was successful」と出たら完了です。

> すでに Python が入っている場合は、この手順はとばしてかまいません。

## 2. 初回セットアップ（最初の1回だけ）

1. このフォルダ（ツール一式）を、デスクトップなど好きな場所に置きます。
   GitHub からダウンロードした場合は、ZIP ファイルを右クリック →「すべて展開」してから使ってください（ZIP のままでは動きません）。
2. **「初回セットアップ.bat」をダブルクリック**します。
3. 黒い画面が開き、必要なもの（Excel を作るためのライブラリ）が自動でインストールされます。
4. 「セットアップが完了しました！」と出たら、何かキーを押して画面を閉じます。

> 「WindowsによってPCが保護されました」という青い画面が出たときは、「詳細情報」→「実行」を押してください。

## 3. 使い方

### やり方A：「入力」フォルダに入れてダブルクリック（まとめて処理）

1. 台本（`.md` ファイル）を「**入力**」フォルダに入れます。何個入れてもかまいません。
2. **「セリフ一覧作成.bat」をダブルクリック**します。
3. 黒い画面に結果が表示されます。「警告」があれば、ここにも一覧で出ます。
4. 「**出力**」フォルダに、台本ごとの Excel・テキスト・警告ファイルができあがります。

> 「入力」フォルダには、見本として「第1話_台本.md」が最初から入っています。まずはそのまま実行してみてください。

### やり方B：ドラッグ＆ドロップ（その台本だけ処理）

1. 台本ファイルを、マウスでつかんで「**セリフ一覧作成.bat**」の上に落とします（ドラッグ＆ドロップ）。
   複数のファイルを選んでまとめて落とすこともできます。
2. 結果は同じく「**出力**」フォルダにできます。

どちらのやり方でも、黒い画面は終わったあとも開いたままになります。内容を確かめたら、何かキーを押して閉じてください。

> 同じ名前の台本をもう一度処理すると、「出力」フォルダの古い結果は**上書き**されます。

## 4. できあがるファイルの見かた

### Excel（`○○_セリフ一覧.xlsx`）

「セリフ一覧」シートの列：

| 列 | 中身 | 例 |
|---|---|---|
| 本番号 | 何本目か | 01 |
| 本タイトル | 本のタイトル | バイト帰り |
| コマ | コマ番号 | 1 |
| 話者 | 誰の台詞か | 結衣 |
| 種類 | 台詞／心の声／モノローグ／寝言／効果音 など | 心の声 |
| テキスト | 「」の中身 | バイト終わりは、さすがにしんどい…… |
| 文字数 | テキストの文字数 | 18 |
| 絵（参考用） | そのコマの絵の説明 | 夜。雨。傘をさして歩く結衣。疲れた顔 |

- **オレンジ色の行は効果音（描き文字）** です。白い行が、写植する台詞です。
- 本が変わるところには青い線が引いてあります。
- 1行目の **▼ボタン** で、「話者が結衣の行だけ」「効果音以外だけ」のように絞り込めます。
- 「警告」シートに、チェックで見つかった問題がまとまっています。
- 「見かた」シートに、色の意味などの説明があります。

効果音の種類には補足が付きます（例：`SE（奥）「シュンシュン……」` → 種類「効果音（奥）」）。

### テキスト（`○○_セリフ一覧.txt`）

メモ帳で開けます。こんな形です：

```
━━━━━━━━━━━━━━━━━━━━
01「バイト帰り」
━━━━━━━━━━━━━━━━━━━━
【1コマ】
バイト終わりは、さすがにしんどい……

【2コマ】
……ん？
```

台詞1つが1行になっているので、写植ソフト（CLIP STUDIO PAINT など）に1行ずつコピペできます。
台詞のないコマは書かれません（設定で書くようにもできます）。

- 効果音を含めるかどうか、話者名（`結衣（心）：`）を付けるかどうかは、[設定](#6-設定を変える)で切り替えられます。
- 「出力サンプル」フォルダの `第1話_台本_セリフ一覧（効果音あり・話者名あり）.txt` は、両方を「はい」にしたときの見本です。

## 5. 警告（チェック機能）

台本を読み取るときに、次のことを自動でチェックします。見つかった問題は、黒い画面・`○○_警告.txt`・Excel の「警告」シートに表示されます。

| 警告の種類 | どんなときに出るか |
|---|---|
| コマ数 | コマが4つではない本がある（数は設定で変えられます） |
| コマ番号 | コマ番号が飛んでいる（1・2・4 など）、重なっている（1・2・2・3 など）、順番が入れ替わっている |
| 長い台詞 | 台詞の文字数が上限（最初は30文字）を超えている |
| 読み取れない箇所 | 書き方が読み取れない台詞や表の行がある |
| 本番号 | 同じ本番号が2回以上出てくる |

警告には「**何行目か**」「**どの本の何コマ目か**」「**問題の箇所の文字**」が付いているので、台本のどこを直せばいいか分かります。メモ帳で台本を開き、「Ctrl + G」で行番号を指定するとその行へ飛べます（右下に行番号が表示されます）。

警告の例（「出力サンプル」の `警告テスト用_台本_警告.txt` より）：

```
・［読み取れない箇所］ 17行目・02「番号の飛びと重複」・2コマ目：「」（かぎかっこ）が見つかりません
      → 花子 こんにちは
・［コマ数］ 3行目・01「コマが足りない」：コマが3つあります（4コマではありません）
・［長い台詞］ 15行目・02「番号の飛びと重複」・1コマ目：35文字あります（上限 30文字）
```

> 警告が出ても、読み取れた部分の一覧はちゃんと作られます。読み取れなかった台詞だけが一覧から抜けているので、台本を直してもう一度実行してください。

## 6. 設定を変える

「**設定.ini**」をメモ帳で開いて、`=` の右側を書きかえ、上書き保存します（右クリック →「プログラムから開く」→「メモ帳」）。

| 設定 | 最初の値 | 意味 |
|---|---|---|
| 台本の形式 | 4コマ | 今は「4コマ」だけ |
| 1本あたりのコマ数 | 4 | これと違う本があると警告。0 でチェックしない |
| 文字数の上限 | 30 | これより長い台詞があると警告。0 でチェックしない |
| 効果音も文字数チェックする | いいえ | 効果音にも文字数の上限を当てはめるか |
| テキストに効果音を含める | いいえ | テキストファイルに効果音を入れるか |
| テキストに話者名を付ける | いいえ | テキストファイルの台詞の前に `結衣（心）：` を付けるか |
| テキストに台詞なしのコマも書く | いいえ | 台詞のないコマも `（台詞なし）` と書くか |

ほかに、次のものも変えられます：

- **［種類の略号］**：`（心）`→心の声、`（モ）`→モノローグ のような対応表。新しい略号は1行追加するだけで使えます（例：`ナ = ナレーション`）。ここにない略号は、そのままの文字が種類になります（例：`（電話）` → 電話）。
- **［効果音の話者名］**：効果音として扱う話者名。最初は `SE、効果音`。

> 文字数は、空白を数えずに数えます。「……」は2文字、「！？」も2文字です。

## 7. 台本の書き方のルール

見本の「第1話_台本.md」と同じ書き方なら、そのまま読み取れます。

```markdown
### 01「バイト帰り」

| コマ | 絵 | 台詞・音 |
|---|---|---|
| 1 | 夜。雨。傘をさして歩く結衣 | 結衣（心）「バイト終わりは、さすがにしんどい……」 |
| 2 | ふと立ち止まる結衣 | SE「……ミー」／結衣「……ん？」 |
| 3 | 路地の隅の段ボール箱 | ― |
| 4 | 段ボールの中の少女 | 結衣「……え」 |
```

- `### 番号「タイトル」` の見出しごとに1本です。
- 見出しの下の、「コマ」と「台詞」の列がある表だけを読みます（列の順番は入れ替わっていても大丈夫です）。
- 台詞・音の欄の書き方：
  - `話者「セリフ」` … 普通の台詞
  - `話者（心）「…」` … 心の声。`（モ）`＝モノローグ、`（寝言）`＝寝言 など
  - `SE「…」` … 効果音。`SE（奥）「…」` のように補足を付けられます
  - 1つのコマに複数あるときは `／` で区切ります（「」の中の `／` は区切りになりません）
  - `―` は台詞なし
- 話者の名前は自由です。どんな名前でも読み取れます。
- 表の外にある説明文・箇条書き・`[提案]` などの注記・`[[リンク]]`・コマの表ではない表（「元の構成からの変更点」など）は無視します。
- `## 見出し` や `---`（区切り線）が出てきたら、その本の範囲は終わりです。

## 8. 困ったとき

| こんなとき | どうする |
|---|---|
| 「Python が見つかりません」と出る | 「1. Python を入れる」をやり直してください。「Add python.exe to PATH」のチェックを忘れずに。インストール後はパソコンを再起動すると確実です |
| 「openpyxl が入っていません」と出る | 「初回セットアップ.bat」を実行してください |
| 「書き込めません。Excel やメモ帳で開いたままになっていませんか？」と出る | 「出力」フォルダのファイルを開いたままにしていると上書きできません。閉じてからもう一度実行してください |
| 「入力フォルダに台本がありません」と出る | 「入力」フォルダに `.md` ファイルが入っているか確かめてください。拡張子が `.md.txt` になっていないかも確かめましょう（エクスプローラーの「表示」→「表示」→「ファイル名拡張子」で見られます） |
| 台詞が一覧に出てこない | 警告に「読み取れない箇所」が出ていないか確かめてください。`「` `」` の閉じ忘れや、`／` の打ち忘れがよくある原因です |
| セットアップでエラーになる | インターネットにつながっているか確かめて、もう一度実行してください |
| 画面に英語の長いメッセージ（くわしい情報）が出た | その部分をそのままコピーして、詳しい人に見せてください（黒い画面は、範囲を選んで右クリックするとコピーできます） |

## 9. フォルダの中身

```
serifu-list/
├─ セリフ一覧作成.bat      … これを使います（ダブルクリック／ドラッグ＆ドロップ）
├─ 初回セットアップ.bat    … 最初に1回だけ実行
├─ 設定.ini               … 設定ファイル（メモ帳で編集）
├─ README.md              … この説明書
├─ 第1話_台本.md           … 見本の台本
├─ 入力/                  … ここに台本を入れる
├─ 出力/                  … ここに結果ができる
├─ 出力サンプル/           … 見本の台本で実際に実行した結果
├─ program/               … ツールの本体（ふだんはさわらなくてOK）
├─ tests/                 … 動作確認用のテスト（ふだんはさわらなくてOK）
└─ requirements.txt       … セットアップで入れるライブラリの一覧
```

## 10. （上級者向け）しくみと改造のしかた

ツールの本体は `program` フォルダにあります。役割ごとにファイルが分かれています。

| ファイル | 役割 |
|---|---|
| `program/run.py` | 全体の流れ（ファイルを集める → 読み取る → チェック → 出力） |
| `program/serifu/models.py` | 読み取った結果の「入れ物」（本・コマ・台詞・警告） |
| `program/serifu/parsers/yonkoma.py` | **4コマ台本の読み取り部分** |
| `program/serifu/parsers/common.py` | 台詞欄（`結衣（心）「…」／SE「…」`）の読み取り。どの形式でも共通 |
| `program/serifu/parsers/__init__.py` | 台本の形式と読み取り部分の対応表 |
| `program/serifu/checks.py` | チェック機能（警告を作る） |
| `program/serifu/writers.py` | Excel・テキストの書き出し |
| `program/serifu/settings.py` | 設定.ini の読み込み |

### ページ単位の台本などに対応するには

読み取り部分は差し替えられるようになっています。チェックと出力は「入れ物」（`models.py`）だけを見て動くので、読み取り部分を1つ追加するだけで対応できます。

1. `program/serifu/parsers/` に新しいファイル（例：`page.py`）を作る
2. その中に `parse(text, path, settings)` という関数を作り、`Script`（`Unit`＝ページ、`Panel`＝コマ、`Line`＝台詞）を返すようにする。
   台詞欄の読み取りは `common.py` の `split_items()` と `parse_item()` がそのまま使えます
3. `parsers/__init__.py` の `PARSERS` に `"ページ": page.parse,` を追加する
4. 設定.ini の `台本の形式` を `ページ` にし、`1本あたりのコマ数` を `0` にする（ページごとにコマ数が違うため）

### テストの実行

ツールのフォルダでコマンドプロンプトを開き、次を実行します。

```bash
python -m unittest discover tests
```

`tests/data/警告テスト用_台本.md` は、わざと間違いを入れた台本です。チェック機能の動作確認に使っています。

### コマンドで直接動かす

```bash
python program/run.py 台本.md --out 出力先フォルダ --settings 別の設定.ini
```
